# Hammer Engine: Orange Light

## 2D game engine
Hemmer Engine: Orange Light is an open-source project. The engine is written in C# using the OpenTK library. While it currently offers basic functionality, our team aims to elevate it to the level of well-known solutions like Godot, Cocos, Unity, and Unreal Engine. In the future, we plan to implement full 3D graphics support.
